Project allowance rules
Automatic Project Allowance: each day an employee is recorded at a project (phone, fingerprint machine or hand entry), the matching rule adds its daily amount to their payroll
Which rule applies: 1. this employee at this project · 2. this employee at any project · 3. this job title at this project · 4. this job title at any project. One allowance per day — if someone works at two projects on the same day, the project where they spent most hours counts. Days with “No project” earn nothing. Amounts appear on the payslip as Project Allowance — automatic and are charged to the project in labour costing. Manual amounts on Monthly Entries are added on top.

Bulk upload — variable additions and deductions
1. Download the template, or use your own sheet with these columns: employee_code, element_code, amount, and optionally project_code (an employee_name column is fine too — it is ignored).
2. Fill in one row per employee per element. To split one employee's amount across sites, use one row per project.
3. Upload it as Excel (.xlsx) or CSV. You will see a preview before anything is saved.
For each employee and element in your file, the amounts replace what is already entered for this period. Everyone not in the file is left untouched, so uploading the same file twice is safe.

Import from the HQ fingerprint machine
Use the attendance log file from the ZKTeco machine (USB download, e.g. attend.txt or 1_attlog.dat) or a CSV export from its software. The original punches are stored permanently. Each day becomes one attendance record: first punch = check-in, last punch = check-out; repeat taps within a minute count once; a night shift (evening In as the only punch of the day, then Out next morning) stays together. Days with one punch or more than 16 hours are marked ⚠ for HR and carry no deductions or overtime until corrected. Records typed in by hand or from phones are never replaced; re-importing replaces only earlier machine records. Approved months are skipped.
