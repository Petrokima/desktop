Import from the HQ fingerprint machine
Use the attendance log file from the ZKTeco machine (USB download, e.g. attend.txt or 1_attlog.dat) or a CSV export from its software. The original punches are stored permanently. Each day becomes one attendance record: first punch = check-in, last punch = check-out; repeat taps within a minute count once; a night shift (evening In as the only punch of the day, then Out next morning) stays together. Days with one punch or more than 16 hours are marked ⚠ for HR and carry no deductions or overtime until corrected. Records typed in by hand or from phones are never replaced; re-importing replaces only earlier machine records. Approved months are skipped.
